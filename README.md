# Reel Viewer

A lightweight, single-file web app for watching public Instagram Reels in the browser. Paste a link, watch the Reel, and share a clean link to it. No build step, no dependencies, no accounts.

> **Not affiliated with Instagram.** Reel Viewer is an independent project. See the [Disclaimer](#disclaimer).

## Features

- **Paste and watch.** Accepts full Reel URLs, `instagram.com/reels/…` links, or a bare Reel ID.
- **Shareable links.** Every Reel gets a link of the form `https://your-site/?reel=ID` that opens straight to the player.
- **One-tap helpers.** Paste from clipboard, copy link, native share sheet (where supported), and open the Reel on Instagram.
- **Recently watched.** The last 8 Reels, stored locally in your browser, with per-item remove and clear-all.
- **Light and dark themes.** Follows your system setting, with a manual toggle that is remembered.
- **Responsive and accessible.** Works on phones and desktops, supports keyboard navigation (press `/` to focus the link field), has visible focus states, and respects reduced-motion settings.
- **Browser history support.** Back and forward buttons move between Reels.


## How it works

Reel Viewer uses Instagram’s own public embed page (`instagram.com/reel/ID/embed`) inside an `iframe`. It does not download, copy, re-host or proxy any video. Playback, captions, and the original creator’s attribution all come directly from Instagram.

Because it relies on the embed, a Reel will only play if Instagram allows it to be embedded. Private accounts, removed Reels, and posts with embedding disabled won’t load.

## Privacy

- There are no analytics, cookies, trackers, or server-side code.
- Your recent history and theme choice are saved in your browser’s `localStorage` and never leave your device. Clear them any time with **Clear all** or your browser’s site-data settings.
- Using the viewer makes requests to third-party services, each governed by its own privacy policy:
  - **Instagram** (to load the embedded Reel)
  - **Google Fonts** (to load the typeface)
  - **Meta Graph API** (an optional request to look up a preview thumbnail; if it fails, the Reel still plays)

## Known limitations

- Works for **public** Reels only.
- Link previews on social platforms and messengers use the static meta tags in `index.html`. Their crawlers don’t run JavaScript, so a per-Reel preview image can’t be generated by a static page alone.
- The thumbnail lookup may be rejected by Meta’s API without an access token, in which case the default preview image and a play icon are used.
- Embed behavior is controlled by Instagram and can change without notice.
